SMILE-01 — RAILWAY PACKAGE

This folder is Railway-ready.

Railway currently supports services sourced from a GitHub repository, local directory via Railway CLI, or Docker image.
For the simplest first deployment:
1. Put this folder in a GitHub repository.
2. In Railway choose New Project / Deploy from GitHub Repo.
3. Select the repository.
4. Add OPENAI_API_KEY and GOOGLE_SERVICE_ACCOUNT_JSON under Variables.
5. Share the SMILE-01 Google Doc with the Google service-account email as Editor.
6. Deploy. Railway will use `npm start`.
7. Open deployment logs and look for alternating PASS lines.

The dispatcher includes a small HTTP status endpoint so Railway can keep it as a persistent service.
